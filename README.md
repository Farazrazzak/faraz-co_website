# faraz-co_website

Website for **Faraz Abdul Razzak & Co.**, Chartered Management Accountants, Karachi.

A static multi-page site (13 pages) built from `build.py`.

## Structure
- `build.py` – shared header, footer, Home page and site settings (contacts, WhatsApp number)
- `pages_inner.py` – About, Services, the five service pages, Insights, Contact, Privacy, 404
- `articles.py` – Insights articles (currently samples awaiting approved content)
- `css/site.css` – styles (navy and gold palette, animated headings, services ticker)
- `*.html` – generated pages

## Rebuild
```
python3 build.py
```
